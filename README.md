# 🏥 Doctor Booking Appointment System

A full-stack **Doctor Booking Appointment System** developed using the **MERN Stack**.
This application allows users to view doctors, check doctor details, and book appointments online.

## 🚀 Features

* 👤 User Registration and Login
* 🔐 User Authentication
* 👨‍⚕️ View Doctors
* 📋 View Doctor Details
* 📅 Book Doctor Appointments
* 🗓️ View My Appointments
* 👤 User Profile
* 📱 Responsive User Interface
* 🔗 REST API Integration

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/riturai42/Doctor-Booking-appoinment-System.git
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

```bash
cd backend
npm install
npm start
```
